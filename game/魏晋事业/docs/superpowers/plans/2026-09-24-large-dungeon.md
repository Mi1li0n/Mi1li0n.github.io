# 180×180 分层地牢调整

用户要求：地图180×180，区域不能重复拼贴；营地随机；三个下层出口分别为随机、远处、近处任务门。

- [x] 生成：随机分散区域位置，保留原任务九角色接口，加入不重复的场景结构与侧路，营地安全与三出口按实际路程选址。
- [x] 下层：近出口受本层任务限制，远与随机不受任务限制，全部携带原物品进入新层；三主题可循环但每层重新生成。
- [x] 持久化：压缩地图存档，保留旧格式读取与旧地图尺寸，避免180地图超出浏览器存储限额。
- [x] 界面：手绘地图适配大图，出口与楼层说明符合实际；不增加教程小字。
- [x] 验证：可达性、近远出口路程、结构差异、换层物品/耐久守恒、存档和浏览器操作。

分工：生成器与下层流转分别提供独立精确补丁，主代理负责存储、地图UI、合并与回归。用户已授权修改，沿用现有游戏基础结构。

实现记录：22种区域轮廓，13种新增区域地面装饰；near出口按12–30步选址，far在最大可达步距的75%以上，random在其余可达位置抽取。每层换seed，三主题持续轮换；三出口均下层。存档palette/RLE压缩，实测约0.45MB；旧尺寸地图按原样恢复。

最终验证：196项回归全部通过，含60种子×3章×两种门/潮状态可达性。桌面/手机浏览器真实出口下行、换层卡牌耐久、保存刷新、全图尺寸通过；13种新装饰逐类绘制无浏览器异常，三主题全图已视觉检查。

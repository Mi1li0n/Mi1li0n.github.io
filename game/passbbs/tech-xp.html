Windows XP 清理笔记：C盘又满了
技术宅　发表于 2002-11-10

C盘只剩下三百多M，装个东西就叫空间不足。我开始也觉得奇怪，明明电影和游戏都放在D盘，后来打开“我的文档”看了一圈，发现收来的东西最后还是往这里堆。下面把这次整理的过程记一下，免得下次又满了。

先看自己放了什么

桌面上的“临时”文件夹有四百多M。里面是上次帮人拷的照片，拷完以后谁也没想起来删。还有三个安装文件，下载完时随手选的桌面，装好以后一直留着。

我把要存的归到D盘，重复的那份删掉。光这个文件夹就腾出不少地方，系统目录还没动。

磁盘清理里能找出一批

开始菜单里依次找“程序”“附件”“系统工具”“磁盘清理”，选C盘。扫描完以后会列出临时文件、Internet临时文件、回收站等项目，旁边能看见占了多少空间。把准备清掉的项目选上，再确定。

这次整理的东西我的处理
以前下载的安装包留一个能用的版本，重复的去掉
临时文件用磁盘清理处理
回收站翻一遍，有用的先拿回来
不用的软件在添加或删除程序里卸载
卸载也得看看名字

我这里有两个看图软件、三个播放器，平时真正用的就那么几个。以前装光盘上的软件，一按就是整套安装，连自己也不知道装进来些什么。名字认不出来的先留着，光把认识而且确实不用的卸掉就够忙了。

这次清完够用了。论坛上有人问哪些DLL能删，我没法凭一个名字回答，同名文件还可能放在不同目录。要问的把完整位置也写上。

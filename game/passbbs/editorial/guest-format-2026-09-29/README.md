# 首页、版块活跃度与游客入口调整

日期：2026-09-29。所有页面修改均按文件手工完成，没有使用技能或批量替换脚本。

## 用户确认的设计边界

- 显示总页数大于实际静态文件数是营造热闹气氛的既定设计。本轮保留全部原有分页条和页数。
- 游客执行发帖、回复、搜索等操作时进入登录引导，属于预期行为。
- 原有特殊跳转可能是刻意设计的彩蛋，不能只凭按钮名称认定为错误。`ls.html` 第一楼“举报”按钮的原始外链已恢复。
- 本轮没有重新分配原有帖子所属栏目，也没有统一改动旧帖的字体、留白、彩色文字或特殊效果。

## 默认入口与首页

- `index.html` 的脚本跳转、无脚本自动跳转和手动链接均改到 `forum.html`。脚本使用替换历史记录的方式进入首页。
- 首页保留 10 个版块、3 个分区，原有版块名称、简介、最新主题链接、最后发表人及已有时间均完整保留。
- 版块区改为紧凑的三列表格：版块和简介／统计／最后发表。没有折叠或隐藏原有信息。
- 在 1366px 宽度下，版块目录从约 964.5px 高缩小到 569px，减少约 41%。
- 目录下新增 8 个跨版块热门主题，来自游戏、音乐、硬件、灌水、软件、编程、贴图、日记；回复数、查看数、作者和最后发表信息沿用对应列表页。
- 首页专用样式放在 `forum-home.css`，保留原蓝灰色表格皮肤。增加了平板和手机排布，避免中等宽度仍被 980px 表格撑开。

## 游客入口

- 20 个原有帖子页的快速回复表单补上 `login.html` 目标。
- 灌水区首页快速发帖从提交当前页改到登录引导。
- 26 页顶部搜索框从向当前页 POST 改为进入登录引导，与主导航“搜索服务”的行为一致。
- 原有的其他帖子链接、作者链接、图片地址和特殊外链全部保留；与备份逐一比较通过。

## 正文格式清理

没有发现直接显示在正文中的 `**文字**`。主要遗留是已经转换为 HTML 的句中加粗，以及紧挨加粗词的多余空格。

逐处清理了 18 个帖子页中的 45 处普通词语加粗，例如宿舍人名、软件名、型号和聊天短句，同时去掉这些片段周围的多余空格。

版规小标题、小说章节名、作者名、论坛标题栏、桌面图示按钮及原有彩色大字等有明确排版用途的格式保留。没有重写帖子的对话内容。

## 对此前“面包屑／视觉差异”的说明

- 面包屑差异是指文字与目标地址不符。例如 `sdrj.html` 顶部显示“技术交流区 → 软件下载”，但链接指向灌水列表；`163.html` 显示“电脑网络 → 网络资源”，也都指向灌水列表。这是原有导航写法，本轮先保留，没有擅自改变旧栏目归属。
- 视觉差异主要是正文内边距 10／15／20px、原有帖与后补帖手机正文 14／15px，以及不同分页样式。这些是外观差异，不能不经判断就视为必须消除的错误。本轮视觉调整集中在用户明确要求的首页。

## 验证

- 全部 264 个 HTML 的本地相对文件链接检查通过。
- 所有原有分页标记、数字和链接与本轮备份相同。
- 所有帖子页的原有 `href`／`src` 列表与备份相同，包括原始“举报”外链。
- 正文可见文字比较通过：除空格和括号形式外，没有修改文字内容；加粗标签按上述范围清理。
- 首页十个版块的名称、简介、最新主题、发表人和原有日期与备份逐项比对通过。
- 热门主题标题、作者、统计、最后回复信息来自已有版块列表，8 个主链接在浏览器内点击通过。
- 无头 Edge 实测：20 个快速回复表单、26 个搜索框、1 个快速发帖表单均到登录提示。
- 默认入口在启用 JavaScript 和禁用 JavaScript 时均进入 `forum.html`。
- 首页在 1366px、768px、390px 宽度下均无横向溢出，桌面和手机截图已目视检查。
- 测试时阻止了外网资源加载，截图里远程头像、图标的未加载状态不作为资源失效结论。

# 论坛框架一致性核对（2026-09-29）

> 后续确认：大页数用于营造论坛规模，是用户要求保留的设计；游客操作进入登录提示也是预期行为。原有特殊外链可能是彩蛋，不能只按按钮名称认定为错误。下面保留的是当时的差异核对记录，不代表每个差异都应被消除。后续首页、版块活跃度、游客表单与正文格式调整见[本轮调整记录](../guest-format-2026-09-29/README.md)。

## 结论与范围

检查了根目录的 264 个 HTML 页面，以及共用样式 `mobile.css`。整体采用相近的旧式论坛视觉，但“看起来相同”不等于导航和交互已经统一。

本轮按文件逐个手工修改，仅修复版块列表页已经确定的分页、跳转菜单错误。没有使用技能、批量替换脚本或自动重写模板。检查脚本只用于读取、比较和验证。

| 页面类型 | 数量 | 核对结果 |
| --- | ---: | --- |
| 10 个版块的列表页，含分页 | 22 | 内嵌基础 CSS、页头、主导航、欢迎区和页脚一致；原先分页和跳转菜单有错误，已修复下述确定问题 |
| 普通帖子页，含续页 | 153 | 980px 主体、作者栏、正文栏、楼层操作、蓝灰配色基本一致；仍有面包屑、回复行为、分页样式和内边距差异 |
| 会员资料页 | 67 | 采用 800px 资料页布局；与帖子页属于不同页面类型，不宜仅因宽度不同判定为错误 |
| 论坛首页、帖子目录、联系页、会员列表 | 4 | 采用完整论坛页头和主导航 |
| 登录提示、帮助、广告删除提示 | 3 | 采用简化框架；登录提示主体为 600px，帮助和删除提示为 980px |
| 个人主页及文章、WAP、跳转和特殊效果页 | 15 | 有独立设计或用途，本轮未强行套入帖子模板 |

帖子页普遍没有版块页那套完整 Logo、主导航和欢迎区，这一点在原有帖和后补帖之间是一致的。单页帖子没有分页条、锁定公告没有快速回复框，也不能单独视为遗漏。

## 已逐页修复

1. **灌水区缺少“上一页”**：`bbs2.html` → `bbs.html`，`bbs3.html` → `bbs2.html`，`bbs4.html` → `bbs3.html`。每页顶部、底部同时补齐，共 6 个按钮。
2. **18 个其他版块列表页的选中项错误**：原先当前选项虽然写着“游戏天地”“编程开发”等，值却仍是 `bbs.html`。现在选中实际所属版块。
3. **22 页跳转菜单统一栏目映射**：每页均包含 10 个实际版块，补齐“心情日记”和“贴图专区”；恢复正确分组，去掉错误的同名重复项。
4. **22 页 Go 行为修复**：原先固定链接到 `forum.html`，现在读取同一表单中所选版块。下拉框选择仍可直接跳转；选择空白提示项不会刷新当前页。

修改文件：`bbs.html`、`bbs2.html`、`bbs3.html`、`bbs4.html`；`board-code`、`board-diary`、`board-feedback`、`board-game`、`board-hardware`、`board-music`、`board-notice`、`board-pictures`、`board-software` 各自的首页和 `-2.html`，共 22 个 HTML。

## 仍未统一的具体项目

这些是本轮核对后保留的明确差异，未宣称已经全部修好。涉及缺失页面和旧栏目归属的项目，需要连同内容结构一起整理，不能仅通过补一个按钮解决。

### 1. 显示总页数与实际页面不匹配

| 版块 | 显示总页数 | 实际列表页数 |
| --- | ---: | ---: |
| 灌水乐园 | 2375 | 4 |
| 编程开发 | 176 | 2 |
| 心情日记 | 640 | 2 |
| 投诉建议 | 63 | 2 |
| 游戏天地 | 1257 | 2 |
| 硬件维护 | 522 | 2 |
| 影视音乐 | 831 | 2 |
| 公告发布 | 13 | 2 |
| 贴图专区 | 308 | 2 |
| 软件下载 | 713 | 2 |

因此，灌水区第 4 页及其他版块第 2 页没有后续页面文件。此次没有添加指向不存在页面的“下一页”，也没有擅自改动用于营造论坛规模的总数。

帖子也有类似情况：红警规则帖只存在第 1、2、20 页，配机帖只有第 1、2、14 页，歌曲列表帖只有第 1、2、28 页；这 9 个页面目前仅有数字页码，没有统一的上一页／下一页按钮。午饭灌水帖则只有第 1、2、8 页。

可选的统一原则是按实际文件分页，或明确呈现为保留部分页的旧帖存档。不能把第 2 页到第 20 页的跳转直接冒充相邻页。

### 2. 部分帖子页码实际跳到登录提示

| 文件 | 错误的分页目标 |
| --- | --- |
| `bg.html` | 第 2、3、4、15 页均到 `login.html` |
| `zq.html` | 第 2、3、4、8 页均到 `login.html` |
| `wt1.html` | 第 3 页到 `login.html` |
| `wt2.html` | 第 3 页及“下一页”到 `login.html` |
| `wt.html` | 第 6、7 页及“上一页”到 `login.html` |

这些都没有相应的目标分页文件。不能因为链接本身指向一个存在的 HTML，就认为分页可用。

### 3. 帖子面包屑与实际栏目不一致

21 个原有帖子页面把“龙腾世纪BBS”根链接指向 `bbs.html`，后补的 132 页使用 `forum.html`。原有帖的栏目文字也经常与链接不一致：

- `163.html` 显示“电脑网络 → 网络资源”，两级都到灌水区，当前论坛首页也没有这两个栏目。
- `dhxy.html`、`wg.html` 使用旧的“电脑游戏区／游戏专版”；当前实际存在的游戏版块是 `board-game.html`。
- `mm.html` 显示“贴图专区”但指向 `bbs.html`，已有实际贴图版块 `board-pictures.html`。
- `nt.html` 显示“公告发布”但指向 `bbs.html`，已有 `board-notice.html`。
- `sdrj.html`、`wtf.html` 显示“软件下载”但指向 `bbs.html`，已有 `board-software.html`。
- `jl.html`、`ls.html`、`ls2.html`、`njy.html`、`zq.html` 还使用当前栏目目录中不存在的旧名称。

返回入口也分为“返回列表”“返回版块”，有些后补帖另带“灌水列表”。整理时应确定主题所属版块，并让面包屑、返回入口和列表收录保持一致。

### 4. 快速发帖／回复行为不一致

- `bbs.html` 的快速发帖为 `method="post" action="#"`，会向当前页提交；其余 21 个版块列表页进入 `login.html`。
- 以下 20 个原有帖子页的快速回复表单没有 `action`，默认提交到当前页；132 个后补帖子页进入 `login.html`：
  `163.html`、`bg.html`、`dhxy.html`、`hah.html`、`hy.html`、`jl.html`、`ls.html`、`ls2.html`、`mm.html`、`njy.html`、`red.html`、`sad.html`、`sdrj.html`、`wg.html`、`wk.html`、`wt.html`、`wt1.html`、`wt2.html`、`wtf.html`、`zq.html`。
- `nt.html` 是锁定公告，保留锁定提示而没有回复表单，属于合理例外。
- 主导航上的搜索入口进入登录提示，但页头搜索框向当前页面 POST；这是共用框架中的静态交互问题，并非某个版块独有。

以上并不意味着项目具有可提交的论坛后端；本次只核对现有静态页面之间是否一致。

### 5. 视觉细节和移动端标记不同

- 正文区域 `.post-bg`：149 页为 10px 内边距，`bg.html`、`hah.html`、`jl.html` 为 15px，`nt.html` 为 20px。
- `hy.html` 缺少其他帖子通用的输入框、`.bold`、标题栏链接等样式规则；签名和字体规则也略有不同。
- 后补 132 页有 `.post-body` 标记，原有 21 页没有；`mobile.css` 的 15px 手机正文规则只覆盖前者。浏览器抽查 `163.html` 与 `adsl.html`，前者正文保持 14px，后者变成 15px。
- `zq.html` 顶部工具表格缺少其他帖子所用的 `m-tools` 标记，窄屏时不会使用相同的工具栏排列规则。
- 帖子分页有版块按钮式、旧帖 `.pages` 容器式、后补帖纯 `[1] [2]` 链接式等多种制式，文案混用 `Pages:` 与“页次”。
- 帖子页脚均显示 `Powered by Discuz! 2.5F`，但原有页与后补页在空行、标签包装等处有差别；版块页页脚带完整链接、版权和处理时间，属于页面类型差异。

## 验证记录

- 比较本轮备份：只有上述 22 个版块 HTML 发生改动，改动限定在分页和版块跳转菜单。153 个帖子页及全部 CSS 文件没有改动。
- 22 页菜单均有 10 个唯一版块目标，名称与目标匹配，当前版块选中正确。去掉当前选中状态后，22 份菜单内容一致。
- 22 页顶部、底部分页内容相同；灌水区新增的 6 个上一页目标正确。
- 检查根目录全部 264 个 HTML 的本地相对 `href`／`src` 文件目标，没有缺失文件。未将“文件存在”当作“链接语义正确”。
- 使用独立无头 Edge 进行实际点击：22 页分别验证当前选项的 Go、下拉框切换到日记版块、改变选项后通过 Go 到贴图版块，共 66 次跳转通过；6 个上一页按钮点击通过。
- 在 1366px 和 390px 宽度下，抽查 `bbs2.html`、`board-game.html`、`163.html`、`adsl.html`、`zq.html`，均未出现页面横向溢出。保存并目视检查了其中 3 页的桌面与手机截图。
- 浏览器测试主动阻止外网资源请求，截图中的远程头像、图标可能显示为未加载；本次不据此认定这些远程资源已失效，也未验证其在线可用性。
